# Task 1: Credit Scoring Model

## Project Description
This project predicts the creditworthiness of individuals using past financial data and a machine learning classification algorithm.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Features
- Loads and processes financial data.
- Trains a machine learning classification model.
- Predicts creditworthiness based on financial information.
- Evaluates the model's performance.

## How to Run

1. Install Python on your system.
2. Install the required libraries:

   ```bash
   python -m pip install pandas numpy scikit-learn
   ```

3. Run the Python script:

   ```bash
   python credit_scoring.py
   ```
